OnChainMake Network Notice

Version 1.1 · Effective June 2026 · Blockchain network notice · Contact: info@onchainmake.com

This Network Notice explains how blockchain network information is handled during the OnChainMake pilot.

During the pilot, OnChainMake may operate on selected EVM-compatible test networks, production networks or staged deployment environments.

1. Network Disclosure

The applicable network for any specific transaction, smart contract interaction, wallet prompt, escrow action, CST, DPP or verifier-related workflow will be identified through one or more of the following: the user interface, wallet prompt, transaction confirmation screen, deployment notice, smart contract address display, direct pilot documentation or administrator communication.

2. User Verification

Users must verify the displayed network, token address, contract address, amount and transaction details before signing any wallet transaction.

3. Third-Party Network Risks

OnChainMake does not control public blockchain networks, wallet providers, gas fees, failed transactions, transaction delays, network congestion, block explorers, bridges, third-party tokens or user wallet security.

4. Pilot Status

Some blockchain-related features may be unavailable, simulated, disabled, staged or manually supervised during the pilot.

Unless expressly confirmed in the user interface or written pilot documentation, no statement on the website should be interpreted as a guarantee that a particular blockchain network, token, smart contract, CST, DPP or escrow deployment is active for production use.

Users should not send funds, tokens or assets to any address unless the Platform clearly instructs them to do so and they have independently verified the transaction details.
